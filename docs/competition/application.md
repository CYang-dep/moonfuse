## 项目简介

MoonFuse 面向需要在 MoonBit 中接入 Linux 用户态文件系统能力的开发者，提供 FUSE 请求解析、操作码建模、错误映射、文件属性、目录项、句柄和文件系统 trait。现有 MoonBit 生态缺少面向 FUSE 的协议级库，开发者只能自行处理二进制头、inode 生命周期和错误语义，重复建设成本高且容易产生边界错误。MoonFuse 不实现某个业务文件系统，而是提供可复用的协议基础层，后续可支撑内存文件系统、归档视图和动态配置文件系统。

### 预期使用场景

1. 教学或测试项目用只读内存目录树挂载为文件系统，验证 lookup/getattr/readdir 流程。
2. 将 ZIP/TAR 等归档元数据暴露为统一的只读文件树，复用协议层而不重复编解码。
3. 将运行时配置、指标和调试信息组织成动态文件目录，供 Linux 工具读取。

## 核心功能范围

- FUSE 固定请求头、操作码和安全的边界读取。
- errno、文件属性、目录项、请求与回复帧的类型化模型。
- Filesystem trait、请求分类、可重试操作判定和句柄模型。
- MoonBit 格式化、接口快照、测试入口和 GitHub Actions 验证。
- 质量指标：截断输入不越界、未知操作返回空值、回复长度按 16 字节头计算。
- 明确不做：本阶段不复制 libfuse 实现，不绑定特定业务文件系统，不承诺非 Linux 平台直接挂载。

## 移植或参考说明

项目参考 libfuse 3 的公开协议和接口文档，以及 bazil.org/fuse 的公开设计思路；代码由 MoonBit 独立重写，不复制上游源代码。当前阶段覆盖协议核心和可扩展接口，Linux native 设备适配、完整操作参数编解码和示例文件系统将在后续版本迭代。
